# Стековая машина (Постфиксная нотация)

Программа реализует стековую машину на Python для вычисления арифметических выражений, записанных в обратной польской (постфиксной) нотации (RPN).

Для работы самой программы используются исключительно стандартные библиотеки Python (`sys`, `math`) — **установка сторонних зависимостей не требуется**.

## Поддерживаемые операции

* Бинарные арифметические операторы:
  * `+` — сложение (`x + y`)
  * `-` — вычитание (`x - y`)
  * `*` — умножение (`x * y`)
  * `/` — деление (`x / y`)
* Специальный оператор `~`:
  * Если оба операнда не равны 0: вычисляет модуль разности `|x - y|` и помещает результат обратно в стек.
  * Если хотя бы один из операндов равен 0: вычисляет сумму всех значений в стеке, возводит её в квадрат и кладет результат обратно в стек.

## Запуск программы

Программа запускается напрямую через стандартный интерпретатор Python 3. Выражение передается через аргументы командной строки.

> **Примечание:** Рекомендуется оборачивать выражение в кавычки, чтобы оболочки (`bash`, `zsh`) не раскрывали символ `~` в путь к домашней директории пользователя.

```bash
python3 main.py "3 0 4 ~ 2 ~"
```

Пример вывода:
```text
Шаг  1: токен '3' -> стек: [3]
Шаг  2: токен '0' -> стек: [3, 0]
Шаг  3: токен '4' -> стек: [3, 0, 4]
Шаг  4: токен '~' -> стек: [9]
Шаг  5: токен '2' -> стек: [9, 2]
Шаг  6: токен '~' -> стек: [7]

3 0 4 ~ 2 ~ = 7
```

Еще один пример:
```bash
python3 main.py "2 2 + 4 - 4 ~ 2 3 * +"
```

Вывод:
```text
Шаг  1: токен '2' -> стек: [2]
Шаг  2: токен '2' -> стек: [2, 2]
Шаг  3: токен '+' -> стек: [4]
Шаг  4: токен '4' -> стек: [4, 4]
Шаг  5: токен '-' -> стек: [0]
Шаг  6: токен '4' -> стек: [0, 4]
Шаг  7: токен '~' -> стек: [0]
Шаг  8: токен '2' -> стек: [0, 2]
Шаг  9: токен '3' -> стек: [0, 2, 3]
Шаг 10: токен '*' -> стек: [0, 6]
Шаг 11: токен '+' -> стек: [6]

2 2 + 4 - 4 ~ 2 3 * + = 6
```

### Справка

Для получения информации о доступных параметрах и синтаксисе используйте флаг `--help`:
```bash
python3 main.py --help
```

## Тестирование и виртуальное окружение (опционально)

Установка виртуального окружения и зависимостей из `requirements.txt` требуется **только для запуска тестов и замера покрытия кода** (`pytest`, `pytest-cov`).

### 1. Подготовка окружения

#### Вариант А: С использованием uv
```bash
# Создание виртуального окружения
uv venv

# Активация виртуального окружения
source .venv/bin/activate

# Установка зависимостей
uv pip install -r requirements.txt
```

#### Вариант Б: С использованием стандартного venv
```bash
# Создание виртуального окружения
python3 -m venv .venv

# Активация виртуального окружения
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Запуск тестов и проверка покрытия

Запуск тестов:
```bash
pytest
```

Запуск тестов с отчетом о покрытии кода:
```bash
pytest --cov=main --cov-report=term-missing
```

Генерация интерактивного HTML-отчета:
```bash
pytest --cov=main --cov-report=html
```

Покрытие кода тестами составляет **100%**.
