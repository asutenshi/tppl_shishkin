# Токенизатор

Лексический анализатор: превращает исходный код из файла в последовательность токенов.

## Требования

- Python 3.10+
- Для запуска программы сторонние библиотеки не нужны. `pytest` и `pytest-cov` нужны только для тестов.

## Запуск

```bash
cd tokenizer
python main.py <путь_к_файлу>
```

Пример. Входной файл `input.txt`:

```
x = y * 2 + z * 3
```

```bash
python main.py input.txt
```

Вывод:

```
(IDENT, x, 1:1)
(OP, =, 1:3)
(IDENT, y, 1:5)
(OP, *, 1:7)
(INT, 2, 1:9)
(OP, +, 1:11)
(IDENT, z, 1:13)
(OP, *, 1:15)
(INT, 3, 1:17)
```

Каждый токен выводится в формате `(<тип>, <значение>, <строка>:<столбец>)`. Позиция указывает на начало токена, нумерация с 1.

## Что распознаётся

| Тип       | Что это                                                                   |
|-----------|---------------------------------------------------------------------------|
| `IDENT`   | буквы, цифры и `_`, не начинается с цифры                                 |
| `KEYWORD` | `if`, `else`, `while`, `return`, `for`, `def`                             |
| `INT`     | целое число: `42`                                                         |
| `FLOAT`   | вещественное число: `3.14`, `1.`                                          |
| `STRING`  | строка в двойных кавычках (в значении кавычки сохраняются): `"abc"`       |
| `OP`      | `+ - * / = < > == <= >=`                                                  |
| `SEP`     | `( ) { } , ;`                                                             |

Пробелы, табуляции, переводы строк и комментарии (от `#` до конца строки) пропускаются.

## Ошибки

Ошибки выводятся в stderr в формате `<файл>:<строка>:<столбец>: lexical: <сообщение>`.

Пример. Входной файл `input.txt`:

```
a @ b
```

```bash
python main.py input.txt
```

Вывод в stderr:

```
input.txt:1:3: lexical: unexpected character '@'
```

Лексическая ошибка возникает при недопустимом символе и при незакрытой строке. При ошибке токены не выводятся.

Коды возврата:

| Код | Когда                                                              |
|-----|--------------------------------------------------------------------|
| 0   | файл успешно разобран                                              |
| 1   | лексическая ошибка, файл не найден или не читается (не UTF-8)      |
| 2   | неверное число аргументов командной строки                         |

## Тесты

Сначала нужно создать виртуальное окружение и установить зависимости. Это можно сделать одним из двух способов.

С помощью `pip`:

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

С помощью `uv`:

```bash
uv venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
uv pip install -r requirements.txt
```

Запуск тестов:

```bash
python -m pytest
```

Покрытие:

```bash
python -m pytest --cov=main --cov-branch --cov-report=term-missing
```
