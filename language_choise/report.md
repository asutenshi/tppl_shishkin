## 1. Обработка больших данных в реальном времени
- **Парадигма:** Императивная, параллельная
- **Язык программирования:** C++
- **Обоснование:**
    - **Производительность и контроль памяти:** Поток ~3,4 ГБ/с и бюджет 10 мс/кадр исключают языки с GC — паузы сборщика приведут к переполнению буфера и потере кадров. C++ позволяет выделить память заранее (ring buffer) и избежать аллокаций в цикле.
    - **Параллелизм и SIMD:** Подсчёт метрик кадра распределяется по потокам CPU/GPU, а пиксельные вычисления ускоряются векторными инструкциями.
    - **Экосистема:** Нативная поддержка высокопроизводительных библиотек компьютерного зрения и вычислений (OpenCV, Intel IPP, CUDA) без накладных расходов на обёртки.

## 2. Прототип ML-сервиса для прогноза погодных условий
- **Парадигма:** Объектно-ориентированная, императивная
- **Язык программирования:** Python
- **Обоснование:**
    - **Скорость прототипирования (MVP за 2 недели):** Динамическая типизация и лаконичный синтаксис позволяют быстро экспериментировать и менять архитектуру.
    - **Богатая ML-экосистема:** Готовые библиотеки под весь пайплайн — `pandas`/`numpy` (данные), `scikit-learn`/`prophet`/`pytorch` (модели), `matplotlib` (визуализация).
    - **Профиль нагрузки:** Расчёт 1 раз в сутки не требует постоянной низкой задержки, а тяжёлые математические вычисления внутри библиотек и так выполняются на C/CUDA.
    - **ООП-абстракции:** Единый интерфейс моделей (например, `fit`/`predict`) позволяет заменять алгоритмы без переписывания остального кода.

## 3. Интерактивный UI для торгового терминала
- **Парадигма:** Реактивная + декларативная
- **Язык программирования:** TypeScript (React + RxJS)
- **Обоснование:**
    - **Реактивность (RxJS):** Потоки с WebSocket, REST API и действия пользователя объединяются операторами (`merge`, `combineLatest`). Виджеты автоматически реагируют на изменения данных без сложного ручного связывания.
    - **Производительность (< 16 мс / 60 FPS):** Декларативный UI (React) в связке с мемоизацией (`React.memo`) и троттлингом обновлений перерисовывает только изменившиеся виджеты.
    - **Надёжность и типизация:** Статическая типизация TypeScript исключает ошибки несовпадения контрактов данных при 50+ связанных виджетах.
    - **Тестируемость:** Логика преобразования данных тестируется отдельно как чистые функции и marble-тесты RxJS, а UI — изолированно через компонентные тесты.

## 4. Прошивка для устройства регистрации температуры
- **Парадигма:** Императивная, процедурная
- **Язык программирования:** C
- **Обоснование:**
    - **Жесткие ограничения по памяти (32 КБ RAM, 256 КБ Flash):** Минимальный оверхед, отсутствие runtime-среды и сборщика мусора.
    - **Энергоэффективность и прямой доступ:** Прямая работа с регистрами (GPIO, ADC, таймеры) и инструкциями сна (`__WFI()`) для максимальной экономии батареи.
    - **Детерминированность:** Предсказуемое время отклика на прерывания без внезапных системных пауз.
    - **Переносимость:** Аппаратный слой изолируется в HAL/CMSIS, благодаря чему стандартный код на C переносится компилятором под любую архитектуру микроконтроллеров.
